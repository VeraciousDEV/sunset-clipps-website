# Sunset Clipps Website

A sleek, beachy, groovy updated version of the Sunset Clipps website.

## Content
- 1:1 copy of the original site content from sunsetclipps.com
- Updated typography (Poppins + Pacifico)
- Modern beachy layout with ocean, teal, and sunset gold colors
- Responsive design
- Mobile navigation
- Contact form (demo)

## How to Use
1. Clone or download this repo.
2. Open `index.html` in any browser, or use Live Server in VS Code.
3. Upload the files to GoDaddy or any static host.

## Pages
- index.html - Home
- about.html
- services.html
- reviews.html
- contact.html

## Booking
Links to the existing Square Appointments system.
